# API de génération de texte avec FastAPI, Ollama et Qwen  ## 1. Description du projet  Ce projet consiste à développer une API REST de génération de texte basée sur un modèle de langage (LLM).  L'API est développée avec **FastAPI** et communique avec **Ollama**, qui assure l'exécution locale du modèle **Qwen2.5 0.5B**.
